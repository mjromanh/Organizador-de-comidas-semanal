# Planes generados

Cada corrida de `/planificar-semana` guarda aquí el plan completo de esa semana,
con el nombre `semana-AAAA-MM-DD.md` (la fecha es el martes que abre el ciclo).

Estos archivos son el historial de lo planificado. `/cerrar-semana` toma el más
reciente para actualizar la bitácora.
